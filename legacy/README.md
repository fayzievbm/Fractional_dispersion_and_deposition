# Original programs

These are unchanged copies of the original `Drob_1.py`, `Drob_2.py`, `Drob_3.py`, `Drob_4.py`, and `modul.py` supplied with the research materials. Their original authorship comments are retained.

The current manuscript results are generated by `../chapter3_simulations.py` and `../make_figures.py`. The original files contain earlier mesh, parameter, indexing, and update choices. In particular, `Drob_2.py` sets a spatial order of 0.9, outside the interval (1, 2] used in the present manuscript, and its concentration balance uses the ordinary deposit increment. The plotting helpers include hard-coded labels and index choices. Accordingly, these files are archived as provenance and are not the validated reproduction entry points.

Their imports require NumPy, SciPy, and Matplotlib. If inspecting the original programs, keep all five files together so that `import modul` resolves. Running them may write JPG files in the working directory. Use the main workflow in the repository README to reproduce the current manuscript figures and numerical results.
